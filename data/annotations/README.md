# Notice to Action Ground-Truth Annotations

This directory contains human-verified ground-truth annotations for evaluating the **Notice to Action** extraction pipeline against PRD Section 9 targets.

## Annotation Philosophy & Rules

1. **Annotate from Source, Not Model Output**:
   - Always annotate directly from the raw PDF text dump generated by `scripts/make_annotation_stub.py`.
   - Never copy from model predictions; ground truth must serve as an independent reference to prevent confirmation bias.

2. **Zero Hallucination / Null on Absence**:
   - If a notice has no deadline, leave `explicit_deadlines: []`. Do not invent or assume common dates.
   - If submission channels, penalties, or documents are absent, record them as `null` or empty lists.

3. **Verbatim Evidence Passages**:
   - Every entry in `critical_evidence_passages` must be an exact verbatim substring from the cited 1-indexed page.
   - The validator (`scripts/validate_annotations.py`) automatically verifies that quotes exist on their declared pages.

---

## Annotation File Schema (`schemas/annotation.schema.json`)

Each annotation is a JSON file named `<notice_id>.json` conforming to `schemas/annotation.schema.json`:

```json
{
  "notice_id": "tax_or_payment",
  "source_pdf": "tests/fixtures/tax_or_payment.pdf",
  "expected_category": "tax_or_payment",
  "expected_status": "processed",
  "explicit_deadlines": [
    {
      "date": "2026-12-31",
      "original_wording": "paid in full on or before 31-12-2026",
      "description": "Property tax payment deadline",
      "is_ambiguous": false,
      "ambiguity_reason": null
    }
  ],
  "required_documents": [
    "statutory tax demand challan",
    "bank challan"
  ],
  "action_steps": [
    "pay the outstanding property tax dues amounting to Rs. 24,600",
    "Payment can be deposited online via municipal revenue treasury portal or at designated banks",
    "quote your taxpayer identification number on the bank challan"
  ],
  "submission_channel": "online via municipal revenue treasury portal or at designated banks",
  "penalties": [
    "interest under statutory provisions at 1% per month plus a penal cess of 10% shall be levied on tax arrears",
    "Distress warrants and attachment of municipal property will be initiated against defaulting assesses"
  ],
  "ambiguous_or_missing_notes": "Single unambiguous calendar date. Penalties explicitly stated on page 2.",
  "critical_evidence_passages": [
    {
      "field": "deadline",
      "page": 1,
      "quote": "The statutory tax demand challan must be paid in full on or before 31-12-2026."
    },
    {
      "field": "submission_channel",
      "page": 1,
      "quote": "Payment can be deposited online via municipal revenue treasury portal or at designated banks."
    }
  ]
}
```

## Annotation Workflow

### 1. Generate an Annotation Stub & Page Text Dump
```powershell
python scripts/make_annotation_stub.py tests/fixtures/tax_or_payment.pdf
```
This produces:
- `data/annotations/tax_or_payment.json`: empty template with metadata and empty arrays.
- `data/annotations/tax_or_payment_pages_dump.txt`: readable text with `[PAGE 1]`, `[PAGE 2]` markers.

### 2. Fill in Ground Truth
Read `<notice_id>_pages_dump.txt` and fill in:
- `expected_category`: one of `tax_or_payment`, `bank`, `utility`, `scholarship_or_college`, `government_scheme`, or `other_out_of_scope`.
- `expected_status`: `processed`, `needs_clearer_document`, or `out_of_scope`.
- `explicit_deadlines`, `required_documents`, `action_steps`, `submission_channel`, and `penalties`.
- `critical_evidence_passages`: paste exact verbatim quotes with their 1-indexed page numbers.

### 3. Validate Annotations
```powershell
python scripts/validate_annotations.py
```
Checks:
1. Schema conformity against `schemas/annotation.schema.json`.
2. Verbatim presence of every quote in `critical_evidence_passages` inside the target PDF.
